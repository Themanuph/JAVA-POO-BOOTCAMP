# Sistema de Gestion de un Refugio de Animales

## Autor
Tu nombre y apellido

## Descripcion
Programa de consola desarrollado en Java para gestionar
un refugio de animales.

Permite registrar perros y gatos, consultar sus datos,
buscar animales por ID y gestionar adopciones.

## Clases

- Animal: clase padre con los datos generales.
- Perro: clase hija que representa a los perros.
- Gato: clase hija que representa a los gatos.
- Refugio: administra la coleccion de animales.
- Main: contiene el menu y la interaccion con el usuario.

## Funcionalidades

- Registrar perros y gatos.
- Mostrar animales registrados.
- Buscar animales por ID.
- Adoptar animales.
- Validar los datos ingresados.
- Controlar errores mediante try-catch.

## Ejecucion

Abrir el proyecto en un entorno Java y ejecutar Main.java.
o usar este comando en la terminal:
javac -encoding UTF-8 -d bin src\*.java
java -cp bin Main
Asegurense de estar en la carpeta exacta.
